# Fable review evidence

Evidence produced by the independent reproduction/audit pass ("Fable
review") of handoff v0.2.0. Three separately labelled layers:

- `received_current/`: byte-for-byte snapshot of the handoff's
  `evidence/current/` **as received**, taken before any command was
  run. `scripts/verify.py` overwrites `evidence/current/` (also on
  failure), so this directory is the authoritative record of what the
  handoff claimed. Also contains: the `SHA256SUMS` check performed on
  the freshly extracted tree, a hash of every extracted file, and the
  hashes of the received artifacts (ZIP, reports, source book).
- `baseline/`: this review's own reproduction of the received
  package with **no source modifications** (toolchain install log,
  dependency commits, clean `lake build`, `scripts/verify.py`).
- `final/`: the same commands re-run on the repaired package, plus
  the axiom queries, declaration inventory, environment record and
  archive-validation log.

Nothing in `evidence/` outside this directory was modified except
`evidence/current/`, which is regenerated by `scripts/verify.py`.
The legacy original-file logs (`evidence/Proof*.log`,
`evidence/aggregate.log`, `evidence/summary.json`,
`evidence/build_environment.md`, `evidence/proof09_probe.log`) and
the original submission (`evidence/source/mathlib-proofs-16.zip`)
are intentionally untouched; their recorded failures describe the
*original* submitted files, not this project.
